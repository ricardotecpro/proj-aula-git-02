Sincronização de Códigos

Entendendo o Git Pull e Fetch

Aprenda como obter as atualizações feitas em um repositório remoto (GitHub) e sincronizá-las no seu computador de forma segura.

📡 Sincronização: Remoto vs Local

Quando múltiplos desenvolvedores trabalham no mesmo repositório, ou quando você trabalha de computadores diferentes, o repositório remoto (GitHub) avança enquanto seu repositório local fica desatualizado. Para sincronizar, você tem duas abordagens primárias:

🔍 git fetch

Baixa o histórico e as ramificações do repositório remoto para a sua máquina (atualiza a ramificação origin/main), mas não altera nem funde nada no seu diretório de trabalho atual.

⚡ git pull

Faz um atalho inteligente: executa automaticamente um git fetch seguido imediatamente por um git merge das ramificações remotas na sua branch local ativa.
